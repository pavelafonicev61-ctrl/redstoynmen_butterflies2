# RedstoynMen Butterflies

Fabric mod for Minecraft 26.2 / Java 25.

Includes common, green and red butterflies, mutations, hives, honey, flowers, spawn eggs and wing animation.

## Build

Requirements: JDK 25 and Gradle 9.5.1.

Windows:

    gradle build --no-daemon

The built JAR will be in `build/libs/`.

There is also a GitHub Actions workflow at `.github/workflows/build.yml` that builds the project with Java 25 and Gradle 9.5.1 and uploads the JAR as an artifact.
